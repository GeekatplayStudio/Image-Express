IMAGE EXPRESS FOR MAC

The easy installation uses a desktop .dmg from the official Downloads page:
https://github.com/GeekatplayStudio/Image-Express/releases

1. Download arm64.dmg for Apple Silicon, or x64.dmg for an Intel Mac.
2. Open the .dmg and double-click Image Express.
3. Click Open if macOS asks, then Install and Open.
4. Keep the app in your Dock for one-click launch next time.

Requires macOS 13 or later. No Terminal, Git, Node.js or Homebrew needed.
If no published release has a Mac .dmg yet, wait for the signed installer.

THIS SOURCE-CODE FOLDER IS NOT THE DESKTOP INSTALLER.
install.command and start.command are developer tools. Use the .dmg above
for the simplest setup. Do not disable Mac security to run an installer.

Full help, including security messages:
https://github.com/GeekatplayStudio/Image-Express/blob/main/docs/MAC_INSTALL.md
